# Blender Sushi Scene

## Overview

This project is a 3D sushi scene created using Blender. The scene includes modeled sushi pieces, a serving plate, and chopsticks arranged in a stylized presentation.

The project was created to practice:

* 3D modeling
* Object placement and composition
* Material creation
* Scene organization
* Rendering fundamentals

## Software Used

* Blender

## Features

* Custom sushi models
* Chopsticks and serving plate
* Basic materials and shading
* Organized scene hierarchy
* Render-ready setup

## Learning Outcomes

Through this project, I learned:

* Basic 3D modeling techniques
* Material assignment
* Scene composition
* Blender workspace navigation
* Rendering workflow

## Future Improvements

* Higher-quality textures
* More realistic lighting
* Advanced materials
* Animation
* Photorealistic rendering
